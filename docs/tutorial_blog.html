Introduction

Are you having a hard time switching from R to Python? Are the syntax errors making you crazy? Here is a step by step guide to help alleviate the frustration over syntax differences in R and Python.

How To

In this section, we will walk through an example data set, see common syntax differences, and finish with a cheat sheet guide of functions in R and their Python counterpart.

Worked Example

To practice the different syntax, we will work through an example using a data set of 2023 college football data. The data can be found in the GitHub repository data folder or on Kaggle at this link.

Next we want to start running an analysis. To do so we need to do a little bit of data cleaning. For this analysis we will focus on teams, conferences, and their win-loss record. The data luckily has all of this for us but not in the correct format. Like in R, we can use Regex to handle the data extraction. We will do this below to extract the conference from the team name (Team) and the win loss record (Win-Loss). The dataset also includes over 150 columns which are not needed for our analysis. Below we also subset the data so that we only see the columns we care about.

# add the conference variable
data["conference"] = (
    data["Team"]
    .str.extract(r"\(([^()]*)\)\s*$", expand=False)
)

# add the win and loss variables
data[["wins", "losses"]] = (
    data["Win-Loss"]
    .str.extract(r"^\s*(\d+)\s*-\s*(\d+)\s*$")
    .astype("Int64")
)

# calculate the win percentage
data["win_pct"] = (
    data["wins"] /
    (data["wins"] + data["losses"])
)

## check things worked by looking at just the selected columns head and tail
# select specific columns to use
check_cols = [
    "Team",
    "conference",
    "Win-Loss",

# take all rows and just the columns in check_cols

Next let’s look at the top conferences plot.

This is just a nice way of visually comparing conferences average win percentages.

Here we see that matplotlib is structured differently than a ggplot. matplotlib actually works a little bit closer to base R plotting. In ggplot, we use the + to add different elements of a plot. In base R you start a plot and then can add things to the plot after the plot is intitialized. This is the same idea for matplotlib.

Common Syntax Differences

This is not an exhaustive list of all syntax differences between the two languages, but this is a list of some of the more common ones I have ran into while switching from R to Python.

Booleans

In R, for booleans we capitalize the whole word (i.e. TRUE). In Python, we only capitalize the first letter (i.e. True).

Indexing

R has index starting at 1 while Python is indexed starting at 0. This is crucial to remember when trying to access elements of vectors. Ex: vec[1:5] pulls the 1,2,3,4,5 elements in R. vec[0:5] will pull the first 5 elements (0, 1, 2, 3, 4) in python.

Missing Value Checks

In R, we use is.na(df$column) to check for NA’s. In Python, we use df[column].isna().

Methods vs. Attributes

In R everything done to an object is done in a function. This includes checking dimensions and types for data. For example, dim(df) return the dimensions of the data and typeof(df$col) returns what data type a column is. In Python, these types of metadata are accessed without parentheses. For example, df.shape returns the shape of the data frame as a tuple and df["col"].dtype returns the data type of the column.

Logic Negation

In R we use ! to negate (if (!is.na(df$col)){}). In python we use not (if not df["col"].isna().any():). We also see here the syntax for if statements and for loops.

Column Selection

With dplyr in R we can use the select function. For example, select(df, col1, col2). In Python we have to use a list of strings with double brackets. For example, df[["col1", "col2"]]

for, and if

In R we construct a for loop by doing:

for (variable in seq) { 
    #code for each iteration
}

In Python we construct a for loop by doing:

for variable in iterable:
    #code for each iteration
    # make sure it is idented

In R we construct an if statment by doing:

if (condition){
    # whatever you want to happen
} else if (condition 2){
    # whatever you want to happen
} else{
    # whatever you want to happen
}

In Python we construct an if statment by doing:

if condition: 
    # indented whatever you want to happen
elif condition: 
    # indented whatever you want to happen
else: 
    # indented whatever you want to happen
